Rajbhasha Hindi Data Log Application – Version 1.0.0

Windows installation package.

Installation:
1. Download Rajbhasha_Application_v1.0.0.zip.
2. Extract the ZIP file.
3. Run Hindi_DataLog_App_Install
5. Approve Administrator permission when prompted.
6. The installer will automatically configure the application.

Supported Windows:
- Windows 10/11
- Windows 8/8.1 (legacy Node.js compatibility)

Application:
http://localhost:5000
